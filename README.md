# Heart Sound Entertainment

Music that moves. Official website of Heart Sound Entertainment.

GitHub Pages serves the compiled website files in this repository. The complete editable React project, original site assets, package lockfile, and build instructions are included in `website-source.zip`.

To update: extract the source archive, install with pnpm, edit `app/page.tsx` or `app/globals.css`, run `pnpm build`, then run `python3 scripts/package-github.py`. Upload the generated public bundle to this repository. No account credentials are included.

Contact submissions are handled by the existing Heart Sound Entertainment HoneyBook contact form. Video and audio are hosted by Wistia and SoundCloud.
